LOCAL OCR MODE

The model will run on your computer.

The image is processed by the backend on this computer (127.0.0.1), not on an online server. This page does not send images to the cloud.

  • The model loads when you run OCR for the first time. Inference uses the CPU and is limited to images up to 6 megapixels.
  • Model weights are not included; you must place the model files in a local folder.
  • The runner uses a PP-OCRv6 baseline. V28/SVTRv2 weights are not available in the public repository.
  • The image is used temporarily during inference and then deleted.
